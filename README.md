# Ergodicity-Aware RL Under Deployment Dynamics Shift

A compact reinforcement-learning research project investigating conventional and ergodicity-aware objectives on a dynamical control system under deployment-time parameter changes.

## Status

Project environment and repository structure initialized.

- Stable-Baselines3
